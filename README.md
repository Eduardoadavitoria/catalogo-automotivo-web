# catalogo-automotivo-web
Projeto de Mostruário de Veículos desenvolvido como Atividade Prática Profissional (APP) para o estágio de Análise e Desenvolvimento de Sistemas do Centro Universitário Multivix.

# ADGVeículos

Sistema web desenvolvido para gerenciamento e divulgação de veículos.

Tecnologias utilizadas:
- HTML5
- CSS3
- Bootstrap
- JavaScript
- LocalStorage

Funcionalidades:
- Cadastro de veículos
- Edição
- Exclusão
- Busca
- Login administrativo
- Dashboard
- Tema claro/escuro
